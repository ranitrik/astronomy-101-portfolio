Exoplanet Detection Using Machine Learning

A binary classification project completed as part of Week 4 of Astronomy 101, organized by Equinox, IIT Guwahati.

Objective

Predict whether a star hosts an exoplanet using astronomical and observational features.

Methods

- Exploratory data analysis
- Feature engineering and preprocessing
- Random Forest, Support Vector Machine, and Logistic Regression
- Stratified five-fold cross-validation
- Model evaluation and prediction submission

Competition Achievement

5th place on the final private leaderboard, with a score of 1.00000, in the Exoplanet Detection Challenge.

Competition: "Exoplanet Detection Challenge on Kaggle" (https://www.kaggle.com/competitions/exoplanet-detection-challenge/)

Reproducibility

The notebook documents the modelling workflow. Dataset access and execution may require the original competition files and environment.
