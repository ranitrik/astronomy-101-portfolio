Andromeda Galaxy (M31) Image Processing

An astronomical image-processing project completed as part of Astronomy 101, organized by Equinox, IIT Guwahati.

Processing Workflow

The project involved processing astronomical image frames to reveal the structure of the Andromeda Galaxy.

The workflow included:

- Calibration and stacking using DeepSkyStacker
- Background extraction using Siril
- Colour calibration
- Richardson–Lucy deconvolution
- Histogram stretching and noise mitigation

Final Result

The final processed image of M31 will be presented alongside an original or intermediate image to illustrate the processing workflow.
