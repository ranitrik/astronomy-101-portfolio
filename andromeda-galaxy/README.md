Andromeda Galaxy (M31) Image Processing

An astronomical image-processing project completed as part of Astronomy 101, organized by Equinox, IIT Guwahati.

Objective

Process astronomical images of the Andromeda Galaxy (M31) to reveal its structure while improving background uniformity, colour balance, and image detail.

Processing Workflow

- Calibration and stacking: Combined light, dark, flat, and bias frames using DeepSkyStacker.
- Background extraction: Applied RBF background extraction in Siril.
- Colour calibration: Adjusted colour balance in Siril.
- Deconvolution: Applied Richardson–Lucy deconvolution to enhance image detail.
- Histogram stretching: Adjusted image intensity to reveal faint structures.
- Noise mitigation: Used chrominance noise reduction in LAB colour space in GIMP.
- Artifact analysis: Examined residual artifacts in the processed image.
