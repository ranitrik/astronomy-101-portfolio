Solar Flare Classification

A machine-learning project completed as part of Astronomy 101 by Equinox, IIT Guwahati.

Objective

Classify solar active-region observations to identify M5+ solar flare events using magnetic-field features and machine-learning models.

Methodology

- Exploratory data analysis
- Class-imbalance handling using class weighting and SMOTE
- Physics-motivated feature engineering
- Comparison of tree-based classifiers
- Evaluation using precision, recall, F1-score, and ROC-AUC

Project Status

Portfolio documentation in progress. Dataset attribution, reproducibility, and methodology are being reviewed before public release.
